# Анализ отзывов мебельного магазина

## О проекте
Данный проект направлен на автоматизацию анализа клиентского опыта. В базе данных содержится ~13 000 отзывов клиентов мебельного магазина. 
Цель проекта — с помощью  GPT разметить этот массив данных для проверки следующих бизнес-гипотез:

1. Клиенты чаще оставляют негативные отзывы из-за уровня сервиса, а не из-за качества мебели.
2. Высокая скорость доставки значительно повышает вероятность получения положительной оценки.
3. Наиболее частая причина возвратов и претензий — несоответствие товара описанию.
4. Покупатели мягкой мебели оставляют более эмоциональные и длинные отзывы по сравнению с покупателями корпусной.

## Стек технологий
* База данных: PostgreSQL
* Язык: Python
* LLM: Yandex Cloud Foundation Models API (Yandex GPT)
* BI-система: Yandex DataLens

## Структура репозитория
* `src/db/` — скрипты для работы с базой данных и экспорта (в т.ч. выгрузка для DataLens).
* `src/llm/` — скрипты взаимодействия с API Яндекса (классификатор, расчет метрик, проверка гипотез и массовая обработка).
* `metrics_report.txt` — зафиксированные метрики качества модели на тестовой выборке (Accuracy > 80%).
* `data/` — директория для хранения сырых и обработанных данных (добавлена в .gitignore для предотвращения пуша тяжелых файлов).
